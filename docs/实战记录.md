# 实战记录

> 每次现场任务填一份。这份文件是作品价值最直接的证据：
> **"降低了多少人力"永远比"用了什么技术"更有说服力。**

## 模板

```markdown
## <日期> · <地点/分中心> · <网段>

- 场景：<无管理员 / 无台账 / 单网段隔离 / 系统版本混杂 等>
- 清单规模：共 ____ 台（其中含 Windows ____ 台，人工处理）
- 载荷：<业务方提供的执行脚本名称/版本>
- 控制端：<RHEL 8.4 + podman，容器 krictfus/ansible:2.9>
- 配置改动：只改了 conf/hosts/*.conf 与 payload/collect.sh
- 执行时长：____ 分钟（开始 ____ → 结束 ____）
- 结果：OK ____ 台 / UNREACHABLE ____ 台 / FAILED ____ 台 / MISSING ____ 台
- 失败原因分布：<不可达 __ / 认证失败 __ / 载荷无产物 __ / 其他 __>
- 目标机残留检查：公钥 ____ 台已回收，____ 台残留（原因：____）
- 对比人工：原需 ____ 人 × ____ 天 → 实际 ____ 人 × ____ 分钟
- 遗留问题与下一步：<...>
```
